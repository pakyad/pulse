# PULSE - ENTERPRISE AI CONFIGURATION SYSTEM
# Reference Model: Six-File Context Methodology

---

## 1. SYSTEM RUNBOOK (CLAUDE.md)
- **Storage Target Boundary**: All installations, code modules, and file updates must run strictly within the `D:` drive context (`D:\FYP\Pulse`). Never reference or write to the `C:` drive pathway.
- **Core Execution Commands**:
  - Active Development Server: `npm run dev`
  - Production Optimization Compilation: `npm run build`
  - Dependency Management: `npm install`

## 2. PROJECT OVERVIEW
- **System Identity**: PULSE is a highly optimized, university-centric e-commerce and information marketplace application.
- **Subsystem Context**: Includes student user registration, multi-service marketplace modules, real-time logistics tracking dashboards, and vendor dashboards.

## 3. ARCHITECTURE
- **Frontend Core Framework**: Next.js with React functional architectures.
- **Styling Pipeline**: Tailwind CSS utility classes.
- **Mobile Environment Engine**: Flutter SDK.
- **Backend Infrastructure Engines**: Firebase suite (Firestore, Authentication, Cloud Storage).

## 4. CODE STANDARDS
- **Functional Paradigm**: Write clean, modular, and strictly-typed TypeScript functional components.
- **Resilience Engineering**: Never assume an API execution succeeds. Wrap network states in explicit error boundaries, custom loading placeholders, and graceful alert components to avoid silent interface crashes.

## 5. UI CONTEXT
- **Design Aesthetic Identity**: Follow a premium, minimalist "Apple-style" mobile and web layout prioritizing geometric discipline and high whitespace configurations.
- **The Zero-Black Protocol**: Use high-contrast monochrome color schemes, 0.5px hairline layout borders, and translucent header component backgrounds.
- **Typography Matrix Constraints**: Restrict all screen layout rendering strictly to these font families: *Inter, Outfit, San Francisco, Grab Community*.
- **Navigation Layout Anchorage**: The application navigation menu structure must remain permanently anchored to the absolute bottom of the screen viewport layout.
- **Logistics CTA Pattern**: Ensure the core action button for logistics tracking triggers is explicitly designated as "Run" with a mature, high-contrast professional styling.

## 6. AI WORKFLOW RULES
- **Persona Context**: Operate exclusively as an elite Full-Stack Software Engineer and Systems Architect.
- **Terminal Dialogue Constraint**: Keep terminal outputs direct, clean, and entirely production-ready. Eliminate long conversational paragraphs, pleasantries, or superficial summaries from your code blocks.
